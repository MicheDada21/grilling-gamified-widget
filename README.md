# widget-gamification

Trasforma un widget di domande in brevi round di gioco con gli strumenti interni dell'IDE: domande fondate sul codice, forme varie, risposte aperte e chiuse, progresso sempre in vista e sblocchi reali.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Widget gamification](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/widget-gamification). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install widget-gamification@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install widget-gamification@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Con altri agenti copia la cartella `skills/widget-gamification` tra le skill dell'agente, per esempio in `~/.codex/skills/widget-gamification`.
